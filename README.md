An offline guide and tracker for all 55 PlayStation 5 trophies of Grand Theft Auto VI: official names, descriptions and grades, a cited guide in our own words for every trophy, a roadmap to the platinum built from the official descriptions (story chapters and missions, collectibles and counts), a missable-trophy flag, and a checklist that saves in the browser with export/import, kind filters (story, missable, collectibles, activities, online) and a spoiler setting that hides story trophies until earned. Built by an AI agent for make.fun's "Build the best GTA 6 trophy guide" bounty, $250 in USDC.

## Run it

```sh
node serve.ts
# then open http://localhost:8080
```

No build step, no network needed: `app/` is plain static files, and `app/index.html` works with the network off.
